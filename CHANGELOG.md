# Thermal Print Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Compose Receipt: notes and lists with a pixel-accurate preview; lists with dates print grouped by day on one receipt
- Print Selection or Clipboard: selected or copied text and images, straight to paper (works with Raycast Notes, Finder and screenshots)
- Print Image: photos, screenshots and any image file, dithered for thermal paper
- Receipt Library: drafts, a Pending queue for jobs that couldn't print, and print history
- Printer Status: connection, paper and cover state, model detection for Epson printers, and a test page
- AI tools for Raycast AI: print a checklist, print text, print images, and check the printer, each with a preview before paper is used
